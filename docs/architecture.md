# Delta Force Audio：功能状态与技术架构

面向 PC 的浏览器音频监听与可视化原型。它可以通过浏览器捕获系统分享音频、麦克风或本地音频文件，并以实时波形展示输入状态。

现在还会对稳定的单音做实时音高识别，显示 C4 为 1 的简谱，并可导出 TXT。识别使用浏览器本地音频数据，不上传音频。适合清晰的单声部旋律；和弦、人声、噪声以及游戏混音可能产生误识别。导出 BPM 只是根据音符间隔估计，当前没有可靠的时值分析，建议导出后校对。

## 本地运行

```bash
cd web
python3 -m http.server 4173
```

打开 `http://localhost:4173`。捕获系统音频时，请在浏览器分享窗口中勾选“同时分享音频”。浏览器对桌面音频捕获的支持依系统和浏览器而异；如没有音轨，可使用麦克风或本地文件。

## 技术路线

项目采用“音频识别 / 曲谱输入 → 演奏调度 → 可替换输入后端”的分层架构：

1. **输入层**：支持浏览器系统音频、麦克风、本地音频和结构化曲谱。
2. **分析层**：完成音高检测、节拍估算、音符稳定化和简谱转换。
3. **映射层**：将标准音符转换为《三角洲行动》口琴键位，并生成带时间戳的演奏事件。
4. **调度层**：由 Windows 桌面客户端进行高精度计时，负责播放、暂停、变速、取消和按键释放。
5. **输出层**：通过统一的 `InputBackend` 接口提供多种实现：
   - `PreviewBackend`：只显示或播放预览，不产生系统输入；
   - `SendInputBackend`：使用 Windows `SendInput`，作为无需额外硬件的基础方案；
   - `SKSimulatorBackend`：接入 [scottfly189/SKSimulator](https://github.com/scottfly189/SKSimulator)，通过外接键鼠模拟器执行硬件级键盘和鼠标输入。

## 密码门摩斯识别架构

该功能与单音简谱识别共用音频输入，但使用独立分析管线，不将提示音转换为 MIDI：

```text
系统 / 游戏共享音频
        ↓
音频帧与频谱分析
        ↓
自动寻找连续、同频的候选提示音
        ↓
带通能量 + 动态噪声门
        ↓
提示音起止与持续时间检测
        ↓
短音“·” / 长音“—”分类
        ↓
五符号分组与数字解码
        ↓
独立网页解码台 / 规划中的 Windows 小窗
```

### 当前实现与后续优化

- 当前网页持续扫描窄带频谱，只有同频、间隔规律的五段提示音组成有效数字时才锁定其频率；单个稳定音调不会触发数字结果。
- 连续出现或消失数帧才切换提示音状态。五段时长与相邻间隔的比例用于短长音分类，时序不清楚时不输出数字。
- 诊断录音的主提示音约在 4.2 kHz，原先 3.0–3.5 kHz 的搜索上限将其排除。现用 AudioWorklet 按音频时钟采样、1024 点频谱以及独立的高频游戏节奏解析路径；常规摩斯时序解析和 30 秒滚动复核仍保留。真实录音回放读出第一段 `083`，用户也报告现场自动识别成功。第二段两次一致读出 `162`，但用户标注为 `435`，需确认录音与标注是否对应；不能硬编码已知答案或宣称该样本已通过。
- 游戏会将同一密码播放两次，两次之间约隔 2 秒。这个间隔是提示音片段的结构先验，不等于整条录音静音 2 秒（背景音仍持续）。后续可先识别重复片段、对齐并强化共同特征，再做点划分段；不可仅用全频音量的静音阈值切分。

## Windows 置顶小窗

纯浏览器页面不能可靠获得系统级始终置顶能力。桌面端计划使用 C# / .NET 8 与 WPF 提供独立显示层：

- 无边框透明窗口、始终置顶、拖动、缩放和位置记忆。
- 鼠标穿透开关以及显示、隐藏、重新识别的全局快捷键。
- 精简显示当前摩斯符号、解码数字、锁频状态和置信度。
- 与主程序共享识别状态，不在小窗内重复捕获或分析音频。
- 优先支持无边框窗口化游戏；独占全屏下不保证置顶显示。

桌面端与浏览器前端之间可使用本机 WebSocket 传递音频状态、符号和识别结果。连接中断时，小窗应明确显示离线状态并停止更新。

### Windows 监听修复（2026-10-04）

原生引擎此前按回调次数分类，长音可能误判为点。现按固定 10 毫秒采样窗计时，在 4.1–4.4 kHz 范围寻找窄带音；模糊时长保留 `?`。桥接发送实际采样率并顺序排队发送音频，网页重组为 1024 采样 / 512 步长分析窗，修复变长包与浏览器采样率不匹配。新网页与 exe 需要一起更新。

网页合成 `083` 的 44.1/48 kHz、多种包长回归已通过（10 项）。浏览器通过模拟 WebSocket 桥接接收 44.1 kHz、每包 1379 采样的音频，实际显示 `----- / ---.. / ...-- → 083`；该验证未使用 Windows WASAPI。原生合成回归已加入 Windows CI（`DecoderRegression`，随每次构建执行）；本地为 macOS 无 dotnet，未在 Mac 本地执行原生回归，WASAPI 现场实听仍需在 Windows 上确认；本次未找到真实录音夹具，原有真实 `083` 结论沿用历史记录，`162`/`435` 差异仍待核对。

### SKSimulator 接入规划

- Windows 客户端使用 C# / .NET 8，与 SKSimulator 的 C# SDK 保持一致。
- 封装 `KMSimulatorService` 的初始化、设备搜索、打开、健康检查和关闭流程。
- 根据运行架构加载 `x64/skm.dll` 或 `x86/skm.dll`，设备 VID、PID 和校验数据放入本机配置，不写入曲谱。
- 将演奏事件映射到 `HKMKeyDown`、`HKMKeyUp` 和 `HKMKeyPress`；停止、异常退出或切换后端时必须释放所有按键。
- 设备调用集中在单一工作线程中，调度层通过队列顺序投递事件，避免并发访问硬件。
- 保留 `SendInputBackend` 和预览模式；未连接硬件、初始化失败或设备中途断开时停止演奏，不自动切换后端继续发送输入。
- 首次启用前提供按键测试、目标窗口确认和紧急停止热键，仅在用户主动启动且目标窗口匹配时输出。

SKSimulator 依赖专用硬件，并非纯软件方案。该后端只作为用户明确选择的可选能力，使用时需遵守游戏规则、设备条款及适用法律。

挥刀误触发补充修复：原生音频识别先缓存脉冲，完整五段需通过同频（偏差不超过 100 Hz）、组内起点间隔 180–520 毫秒及单段频率稳定性校验，才写入点划记录。孤立声效不会直接显示为点；手动点划仍可立即输入。新增孤立音、节奏不规则音、跳频音与宽带噪声的原生合成负例，已纳入 Windows CI（`DecoderRegression`），随构建执行。没有用户真实挥刀录音，尚不能声称已验证该声效被滤除。

### 移动网页练习适配

网页教练已有铺满页面的全屏练习模式：横屏八个圆形琴键、竖屏两排，提供按下即判定、开始/暂停、重来和模式切换。退出全屏及进入后台会暂停。FullScreen API 通过“隐藏浏览器栏”主动触发，失败保留页面全屏。安全区域与动态视口已处理；没有自动横屏锁定。浏览器响应式布局和点击已验证，真实 iOS/Android 触摸、系统全屏及刘海区域未验证。此功能不等于 Android 原生客户端。

网页教练现显示音符拍数、目标秒数、每拍秒数和按住进度，时长按 BPM 与速度计算。自由练习匹配按键按下即前进，松开仅评价持续时间；节奏模式同时判定起点与持续时间。允许 20% 时长误差（最少 60、最多 150 毫秒）。提前松开或持续过久记为失误，但不阻断瀑布播放；取消触摸、暂停、切换模式/速度与失焦会取消当前按住状态。曲谱未标时值时仍默认一拍，不代表已从音频准确识别出时值。

可选瀑布练习（节奏模式）：按 BPM 持续走谱，按键和按住时长只影响评分，漏音、错键与早松/晚松不阻断播放。已过去但仍在持续的长音保留显示。自由练习匹配按键按下即前进，不要求时长合格；释放仅评分。

教练默认模式调整为自由练习：等待匹配当前音符的按键，按下立即平滑滚向下一音。按住时长仅评分，早松或晚松都可继续，持续按住不会重复推进。连续节奏走谱仍作为可选模式。

自由练习在按对按键的瞬间推进，松开只评价时长。音符按拍数、BPM 和练习速度等速平滑下滚（120 BPM、1 倍速时一拍 0.5 秒、两拍 1 秒），保留已有音符节点，逐帧更新位置；快速连续输入会从当前滚动位置继续，避免跳格。减少动态效果偏好下使用即时切换。

练习室布局调整：选曲、开始/暂停、重来和模式选择置于练习面板顶部，曲谱编辑、速度与外观设置收进下方折叠区域。画中画移动整个面板，因此顶部播放与选曲操作也进入小窗；增加八音音阶示例。本地保存曲谱与顶部下拉框同步。画中画期间由小窗动画时钟驱动滚动。

练习室试听修复：琴键使用实时谐波合成，按住持续发声、松开衰减，避免预先计算一分钟音频造成延迟。新增降调（↓，−12 半音）、升调（↑，+12 半音）及半音（Shift，+1）按钮，可叠加；面板显示当前变调与曲谱目标提示。支持上下一个八度及半音曲谱练习，超出范围仍可模拟试听。按键与变调提示为网页操作，不发送游戏输入。

练习室当前音色已替换为 S4CH 的 MuseScore MIDI 合成 MP3，覆盖 C3–D7；在本机加载并循环稳态区支持按住发声，保持模拟演奏、暂停和变调。音频原始来源与许可说明见 `web/assets/s4ch/README.md`（相对于仓库根目录）。未额外添加气息声或颤音。

最新音色调整：S4CH 播放增加轻微带通气息声和延迟进入的颤音（5.2 Hz，最大 ±10 音分，起音 160 毫秒后渐入）。气息、颤音与音符一起松键衰减或暂停停止，短音颤动较弱。此调整覆盖之前“无气息、无颤音”的选择。
