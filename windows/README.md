# Windows 桌面端（实验性）

`DeltaForceMoss/` 为自有 .NET 8 / WPF 源码，提供 WASAPI 默认播放设备捕获、摩斯解码结果置顶小窗以及本机 WebSocket 音频桥接。构建命令见 [客户端说明](DeltaForceMoss/README.md)。Windows 演奏教练与按键输出仍未实现；独占全屏不保证浮窗可见。

点划检测按固定 10 毫秒采样窗累积实际音频时长，扫描 4.1–4.4 kHz 游戏提示音。桥接先发送实际采样率，再顺序发送单声道 float32 音频包；网页重组为 1024 采样、512 步长的分析帧，使用采样时钟。新网页需要新版 exe，旧桥接没有采样率时会要求更新。

原生合成信号回归：`dotnet run --project windows/DecoderRegression/DecoderRegression.csproj -c Release`。覆盖 44.1/48 kHz、不同回调长度和提示音频率的合成 `083`，不等同于真实录音回归。该检查已加入 Windows 构建工作流。本次 Mac 环境没有 dotnet，未执行原生测试、WPF 构建或 WASAPI 游戏实听。

第三方提取程序集仅用于研究，不作为本项目依赖。

挥刀误触发补充修复：原生音频识别先缓存脉冲，完整五段需通过同频（偏差不超过 100 Hz）、组内起点间隔 180–520 毫秒及单段频率稳定性校验，才写入点划记录。孤立声效不会直接显示为点；手动点划仍可立即输入。新增孤立音、节奏不规则音、跳频音与宽带噪声的原生合成负例，已纳入 Windows CI（`DecoderRegression`），随构建执行。没有用户真实挥刀录音，尚不能声称已验证该声效被滤除。
